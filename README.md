## 📌 Project Overview

This project demonstrates **password recovery and password security assessment** using **John the Ripper (JTR)**, **Johnny GUI**, and **Networkwalks tools** in a controlled cybersecurity laboratory environment.

The purpose of this project is to understand how password-protected files can be tested for password strength, how password hashes can be extracted, and how dictionary-based password recovery techniques work.

The project was performed only on **authorized laboratory files and systems** for cybersecurity learning and practical training.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand the concept of password cracking and password recovery.
- Learn how **John the Ripper (JTR)** works.
- Understand the purpose of **Johnny GUI**.
- Extract password hashes from authorized password-protected files.
- Prepare extracted hashes for security testing.
- Perform dictionary-based password recovery.
- Understand the importance of wordlists.
- Compare different password recovery approaches.
- Verify recovered passwords on authorized test files.
- Understand how weak passwords can be vulnerable to dictionary attacks.
- Practice ethical and responsible cybersecurity testing.

# 🔍 What is John the Ripper?

**John the Ripper (JTR)** is an open-source password security auditing and password recovery tool.

It can be used to test password hashes against different password candidates using techniques such as:

- Dictionary attacks
- Wordlist-based attacks
- Brute-force-style approaches
- Rule-based password testing

In this project, JTR is used only against **authorized laboratory hashes**.

---

# 🖥️ What is Johnny GUI?

**Johnny** is a graphical user interface for John the Ripper.

Instead of using only command-line instructions, Johnny provides a graphical interface that makes it easier to:

- Load password/hash files
- Configure attacks
- Select attack modes
- Start password recovery
- Monitor the cracking process
- View recovered passwords
